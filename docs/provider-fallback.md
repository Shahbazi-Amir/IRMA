# Fallback داده صندوق

زنجیره منبع:

1. FIPIRAN زنده و معتبر
2. فایل رسمی CSV منبع‌دار
3. Last Known Good فقط با برچسب stale

`FundDataProviderChain` اولین Dataset غیرخالی و معتبر را انتخاب و منبع هر رکورد را
حفظ می‌کند. خطای منبع بالادست ثبت می‌شود. فایل رسمی با Provider CSV فعلی و مسیر
`IRMA_OFFICIAL_FUND_FILE_PATH` وارد می‌شود؛ اپراتور باید URL/شناسه انتشار رسمی،
تاریخ مشاهده، واحد و Hash را نگه دارد.

رکوردها فقط با شماره ثبت، نماد یا شناسه رسمی تطبیق داده می‌شوند؛ نام به‌تنهایی مبنای
Merge نیست. اختلاف NAV زیر ۰٫۵٪ هشدار و از ۲٪ به بالا خطاست. آستانه‌ها قابل تنظیم‌اند.
