# محدودیت‌ها

- فقط FIPIRAN به‌صورت خودکار فعال است؛ شاخص، بازار ETF، تورم و بانک CSV-only هستند.
- رتبه‌بندی واقعی بدون تاریخچه معتبر انجام نمی‌شود.
- املاک و ارز تحلیل کامل ندارند.
- بک‌تست، صف خرید/فروش و توقف نماد را فقط از فیلد `tradable` ورودی می‌فهمد.
- سناریوها بر فرض‌های کاربر متکی‌اند.
- پیشنهاد سبد مشاوره دارای مجوز نیست.
- احراز هویت کاربران و رمزنگاری پروفایل‌ها هنوز اضافه نشده است.
- Refresh واقعی چندبازاری در CI اجرا نمی‌شود و هیچ تعداد رکورد واقعی ادعا نمی‌شود.
