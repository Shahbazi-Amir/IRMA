# روش پیشنهاددهی

Ruleset نسخه `2026.07.1` از تخصیص پایه ریسک شروع می‌کند و براساس افق، نقدشوندگی، صندوق اضطراری، درآمد ماهانه، افت قابل‌تحمل، تجربه، سبک سرمایه‌گذاری و سقف نوسان‌گیری وزن‌ها را جابه‌جا می‌کند.

قواعد منفی تولید نمی‌کنند و جمع تخصیص دقیقاً ۱۰۰٪ است. مبلغ هر بخش با سرمایه کاربر محاسبه می‌شود. بخش زیر حداقل مبلغ اجرایی حذف و به درآمد ثابت بازتخصیص می‌شود. برای سرمایه یک میلیون تومان نیز خروجی قابل‌اجرا تولید می‌شود.

موتور هیچ بازده بازار، قیمت آینده یا داده ساختگی تولید نمی‌کند و قواعد اعمال‌شده را برمی‌گرداند.
