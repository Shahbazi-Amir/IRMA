# منابع داده

اولویت آینده: سازمان بورس، FIPIRAN، کدال، مدیریت فناوری بورس، بانک مرکزی، مرکز آمار، وب‌سایت رسمی صندوق‌ها و بانک‌ها.

در این نسخه اتصال خودکار به این منابع فعال نشده است؛ علت، نیاز به بررسی Endpoint، شرایط استفاده، پایداری Schema و روش بازتولیدپذیر است. Adapterهای غیرفعال در `/v1/data-sources/status` با برچسب `missing` نمایش داده می‌شوند.

Provider CSV صندوق‌ها اطلاعات زیر را ثبت می‌کند: شناسه منبع، زمان دریافت، زمان مشاهده، واحد، کیفیت، نسخه، SHA-256 داده خام و خطای دریافت. داده مفقود `null` می‌ماند و صفر نمی‌شود.

املاک و ارز فعلاً فقط Interface و مسیر CSV آینده دارند؛ عبارت «داده کافی موجود نیست» باید در UI حفظ شود.
