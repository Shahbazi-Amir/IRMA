# منابع داده

آخرین بررسی فنی: ۲۰۲۶-۰۷-۳۰. اولویت منابع: سازمان بورس، مدیریت فناوری بورس،
مرکز آمار، بانک مرکزی و صفحه رسمی بانک/صندوق.

## FIPIRAN

Provider خودکار صندوق‌ها از سرویس عمومی FIPIRAN استفاده می‌کند:

- فهرست و آخرین NAV: `POST /services/fund/fundcompare/`
- تاریخچه NAV: `GET /services/chart/getfundchart?regno=...&showAll=true`
- شناسه پایدار Catalogue فایپیران: ترکیب (`regNo`, `groupId`)
- واحد داده منبع: ریال

برای فعال‌سازی:

```env
IRMA_FUND_PROVIDER=fipiran
IRMA_FUND_HISTORY_LIMIT=25
```

فرمان آماده‌سازی اولیه:

```bash
IRMA_FUND_PROVIDER=fipiran python scripts/bootstrap_data.py
```

Providerهای صندوق `csv`، `fipiran` و `chain` هستند. در `chain` فقط CSV رسمی
منبع‌دار می‌تواند جایگزین شود و این وضعیت در گزارش و DataSource با منبع فایل
ثبت می‌شود. `IRMA_FUND_HISTORY_LIMIT=0` تاریخچه را غیرفعال می‌کند؛ برای همه
صندوق‌های فعال `IRMA_FUND_HISTORY_ALL=true` قرار دهید. شکست تاریخچه یک صندوق
گزارش می‌شود و داده صندوق‌های موفق حفظ می‌گردد.

تعداد تاریخچه‌های دریافت‌شده در هر اجرا محدود است. timeout، retry و فاصله حداقلی
درخواست قابل تنظیم‌اند. پاسخ در مرز Provider با Pydantic اعتبارسنجی و هش می‌شود.
شناسه تکراری، NAV نامعتبر و تغییر ناسازگار schema باعث شکست شفاف refresh می‌شود.

اگر FIPIRAN در دسترس نباشد، آخرین داده معتبر حفظ و خطای ingestion ثبت می‌شود.
رتبه‌بندی داده قدیمی را کنار می‌گذارد و داده ساختگی جایگزین نمی‌شود.

## CSV

Provider CSV صندوق‌ها اطلاعات زیر را ثبت می‌کند: شناسه منبع، زمان دریافت، زمان مشاهده، واحد، کیفیت، نسخه، SHA-256 داده خام و خطای دریافت. داده مفقود `null` می‌ماند و صفر نمی‌شود.

## وضعیت Providerها

| Dataset | وضعیت | دریافت | محدودیت |
|---|---|---|---|
| صندوق و NAV | فعال | FIPIRAN API یا CSV | تاریخچه هر اجرا محدود است |
| شاخص بازار | CSV-only | فایل رسمی/منبع‌دار | قرارداد API پایدار تأیید نشد |
| بازار ETF و صندوق طلا | CSV-only | فایل OHLCV منبع‌دار | قیمت بازار از NAV جداست |
| تورم | CSV-only | انتشار رسمی مرکز آمار | سال پایه و تاریخ انتشار اجباری |
| محصول بانکی | CSV-only | صفحه رسمی/بازبینی دستی | فقط نسخه معتبر و منقضی‌نشده |

CSVها باید `source_identifier`، `observed_at`، نسخه و واحد را داشته باشند. مقدار مفقود
خالی می‌ماند و صفر نمی‌شود. اجرای مجدد همان تاریخ رکورد تکراری نمی‌سازد. TSETMC و
دریافت خودکار مرکز آمار تا زمان قرارداد فنی پایدار غیرفعال‌اند.
