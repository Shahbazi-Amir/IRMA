# روش رتبه‌بندی صندوق‌ها

رتبه‌بندی فقط داخل نوع یکسان انجام می‌شود و نیازمند بازده، افت، نقدشوندگی، قدمت و کیفیت داده است. Score ترکیبی به CAGR، Maximum Drawdown، نقدشوندگی و کیفیت وزن می‌دهد و سابقه کوتاه را جریمه می‌کند.

اگر ورودی کافی نباشد API رتبه‌بندی را خالی و علت را نمایش می‌دهد. صندوق جوان صرفاً با بازده کوتاه‌مدت «بهترین» معرفی نمی‌شود.
