# کیفیت داده

قواعد شامل schema، تکرار، مقدار مفقود/ناممکن، قیمت یا NAV غیرمثبت، بازه OHLC نامعتبر،
تاریخ آینده، جهش، تغییر واحد/سال پایه، stale و Match مبهم است.

| شدت | اثر بر پیشنهاد |
|---|---|
| info | مجاز |
| warning | مجاز با هشدار |
| error | حذف رکورد از انتخاب ابزار |
| critical | توقف Dataset یا Provider مربوط |

آخرین داده سالم در شکست Refresh حذف نمی‌شود و خطا باید در وضعیت منبع دیده شود.
