# روش محاسبات مالی

- بازده ساده: `final / initial - 1`
- بازده تجمعی: حاصل‌ضرب `(1+r)` دوره‌ها منهای یک
- CAGR: `(1+total_return)^(1/years)-1`
- بازده واقعی: `(1+nominal)/(1+inflation)-1`
- نوسان: انحراف معیار بازده‌های دوره‌ای
- Maximum Drawdown: بیشترین افت از قله قبلی
- Sharpe: میانگین بازده مازاد تقسیم بر نوسان و سالانه‌سازی
- Sortino: میانگین مازاد تقسیم بر انحراف نزولی

سود مرکب و سناریوها نرخ‌های ورودی کاربر را «فرض محاسباتی» معرفی می‌کنند، نه پیش‌بینی یا تضمین.
