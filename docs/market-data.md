# داده بازار

NAV ارزش حسابداری هر واحد صندوق و قیمت بازار مبلغ معامله‌شده است؛ هیچ‌کدام از دیگری
استنتاج نمی‌شود. Provider بازار مستقل است و `stable_id`، OHLC، آخرین/پایانی، حجم، ارزش،
تعداد معامله، بهترین خرید/فروش و وضعیت نماد را می‌پذیرد. نبود هر فیلد `null` است.

نگاشت صندوق FIPIRAN به ابزار بازار وضعیت `confirmed`, `automatic_high_confidence`,
`manual`, `ambiguous` یا `unmatched` دارد. دو وضعیت آخر برای انتخاب ابزار مجاز نیستند.
در ۲۰۲۶-۰۷-۳۰ API عمومی رسمی با قرارداد پایدار و شرایط استفاده روشن تأیید نشد؛ بنابراین
دریافت شبکه غیرفعال و قالب CSV آفلاین فعال است.
