# محصولات بانکی

IRMA نرخ بانکی را حدس نمی‌زند. هر نسخه شامل بانک، محصول، نوع، نرخ اسمی/مؤثر، حداقل
سپرده، مدت، نرخ شکست، تناوب پرداخت، صفحه رسمی، انتشار و بازه اعتبار است.

فقط `official_verified` و `manual_verified` که منقضی نشده‌اند در API پیش‌فرض و پیشنهاد
قابل استفاده‌اند. وضعیت‌های `official_outdated`, `unverified` و `expired` نگهداری
می‌شوند ولی وارد پیشنهاد نمی‌شوند. Provider فعلی CSV-only و نسخه‌دار است.
