# راهنمای کاربر

1. در «پروفایل سرمایه‌گذار» سرمایه، افق، ریسک و نیازهای خود را وارد کنید.
2. در «پیشنهاد سبد» درصد، مبلغ، دلیل، ریسک و روش ورود را ببینید.
3. در «مقایسه صندوق‌ها» فقط داده‌های واردشده و منبع‌دار نمایش داده می‌شود.
4. در «سود مرکب» نرخ فرضی و تورم فرضی را وارد کنید.
5. «تحلیل کوتاه‌مدت» فقط پژوهشی است؛ برای اجرای API باید داده معتبر Bar فراهم شود.
6. «وضعیت داده‌ها» تاریخ، کیفیت، خطا و Adapterهای ناقص را نمایش می‌دهد.

همیشه تاریخ و منبع را بررسی و تصمیم نهایی را با اطلاعات رسمی تطبیق دهید.
