# مقایسه کلاس‌های دارایی

خروجی میان مشاهده تاریخی، شرط فعلی تأییدشده، فرض سناریو و پیشنهاد قاعده‌محور تفاوت
می‌گذارد. معیارهای بازده، بازده واقعی، نوسان، افت، نقدشوندگی، حداقل مبلغ، هزینه،
تازگی و کیفیت فقط در دوره و frequency قابل‌مقایسه محاسبه می‌شوند. نبود داده `null`
است و نرخ تاریخی به‌عنوان بازده آینده نمایش داده نمی‌شود.
